## v1 の誤りの修正

1. **タイムアウト**を選手の判断として扱っていた → タイムアウトはヘッドコーチ等が請求する（競技規則18-1）。GI-TO-01・GI-TO-02 を選手の判断から外した。
2. **チームファウル**を「5つ目から2本」と書いていた → 条文（41-1-1・41-2-1・41-2-2）どおりの表現に修正。
3. **U15 の試合時間**の出典が二次情報だった → 競技規則の第8条補足で確認。
4. **P&R の守り方**が基準規則に合うかを「要確認」とだけ書いていた → 本文に名前がないことを確認し、一般条項に照らした読み方を【推測】として明記（先生の確認が必要）。
